プライバシーポリシー

間取りすとは、個人情報を集めていません。

会員登録・ログインはありません。メールアドレスなども聞きません。

遊んだデータの保存場所

  • 称号・マイ物件・名前・音量などは、あなたの端末のブラウザの中だけに保存されます。制作者のサーバーには送られず、制作者が見ることはできません。
  • 「データの引き継ぎ」で作るファイルも、あなたの端末に保存されるだけです。
  • ブラウザの「サイトのデータを消す」操作をすると、データは消えます。消えたデータを制作者が戻すことはできないので、大事なデータは「データの引き継ぎ」でファイルに保存しておいてください。

使っていないもの

  • アクセス解析（だれが何回遊んだかを調べる仕組み）
  • 広告
  • Cookie（クッキー）

外部のサービスについて

ゲームを表示するために、次のサービスを使っています。ページを開いた時、通信のしくみ上、IPアドレス（ネット上の住所のような番号）やブラウザの種類などが、それぞれのサービスに届きます。制作者がその情報を受け取ることはありません。

  • GitHub Pages（ゲームの置き場所）… GitHub のプライバシーについて
  • Google Fonts（文字のデザイン）… Google のプライバシーポリシー

シェアについて

  • シェア画像は、あなたの端末の中で作られます。
  • 「シェア」ボタンを押した時だけ、端末の共有画面が開くか、文章がコピーされます。勝手に投稿することはありません。
  • シェア画像には「マドリスト名」がのります。本名は入れないでください。
